# Lyra visual assets

These public web assets are derived from the Product-selected Lyra icon source without publishing the 1.69 MB original.

## Source identity

- source dimensions: 1254 × 1254
- source color mode: RGB
- source SHA-256: `b0b68d579411def0652e4ae3d1037376892c3be5e1884bc0f26f0eb88652b43e`

The source was selected by Product on 2026-09-22. Its local-machine path is intentionally not part of this public repository.

## Derived files

- `lyra-icon.png` — 256 × 256 optimized PNG; durable public identity asset.
- `lyra-icon-640.webp` — 640 × 640 WebP; hero display.
- `lyra-icon-64.png` — 64 × 64 PNG; header/small-icon fallback.
- `lyra-icon-180.png` — 180 × 180 PNG; Apple touch icon.
- `lyra-icon-512.jpg` — 512 × 512 progressive JPEG; social/share preview.
- `favicon.ico` — multi-size 16/32/48/64 favicon.

The derivatives were generated with Pillow using Lanczos resampling. They preserve the selected icon while avoiding a full-size source download on ordinary page views.

## Palette basis

The site palette is measured from the selected icon rather than invented independently.

Dominant source colors include:

- `#0a102e` / `#0e1435` — midnight background family;
- `#112365` / `#242475` — deep indigo structure;
- `#313fa0` — stronger indigo boundary;
- `#7ba2f6` / `#8aa4f6` — electric blue glow;
- `#cde1fd` — cool near-white highlight;
- `#8a75f6` — restrained secondary violet, lightened within the icon's luminous edge family to preserve readable contrast.

Do not turn these colors into an excuse for generic purple-gradient AI styling. The icon is the primary visual anchor; the page remains an open editorial architecture document.
