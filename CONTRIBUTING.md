# Contributing

Thanks for the interest in Lyra Memory Architecture.

This repository is currently an early public architecture and research surface, not a released reference implementation.

## Before proposing a change

- Keep examples entirely synthetic.
- Do not include private conversations, memory records, credentials, operational topology, or copied private implementation material.
- Prefer current first-party documentation for comparison claims.
- Describe competing approaches neutrally; do not turn the comparison into a ranking.
- Distinguish implemented private capability from planned or experimental architecture.
- Preserve the boundary that memory is context, not execution authority.

## Changes

Use focused branches and pull requests for material changes after the initial bootstrap. Explain the problem, the bounded change, and how public-safety/research claims were checked.
